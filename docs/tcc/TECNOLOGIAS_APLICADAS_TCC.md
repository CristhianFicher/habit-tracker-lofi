# Tecnologias aplicadas no TCC

No contexto deste TCC, a tecnologia aplicada será utilizada para transformar a discussão teórica sobre foco e organização em uma solução prática, validável e útil para a rotina estudantil. A proposta não se limita à descrição conceitual: ela prevê a construção de um protótipo funcional que permita testar, na prática, estratégias de apoio à produtividade.

## Tecnologias previstas

- **React Native**: base de desenvolvimento do aplicativo móvel, permitindo criar uma interface única para Android e iOS com reaproveitamento de código.
- **Expo**: plataforma que simplifica a configuração, execução e testes do aplicativo durante o desenvolvimento acadêmico.
- **TypeScript**: linguagem para maior segurança no código, facilitando manutenção e evolução do projeto.
- **AsyncStorage**: armazenamento local para persistência de hábitos, sessões de estudo e preferências do usuário.
- **React Navigation**: navegação entre telas, organizando o fluxo de uso da aplicação.
- **Expo AV**: recurso para reprodução de áudio ambiente (como lo-fi), alinhado ao objetivo de apoiar concentração.

## Aplicação prática no trabalho

A aplicação dessas tecnologias permitirá desenvolver um produto mínimo viável com funcionalidades como controle de hábitos, ciclos de foco e ambientação sonora. Assim, o TCC se caracteriza como aplicado por gerar um artefato tecnológico concreto, com potencial de avaliação prática quanto à usabilidade e contribuição para a constância nos estudos.
